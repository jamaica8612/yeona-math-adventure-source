# 작업 이어하기 문서 (HANDOFF)

중단된 작업을 다른 세션·다른 AI가 이어받을 때 이 문서부터 읽는다. 끝나면 갱신한다.

## 프로젝트 한 줄 요약

연아(2022-02-22생, 만 4세)를 위한 무실패 펫 돌보기 게임 "연아의 별냥이 놀이집".
학습 요소 없음(순수 장난감). Unity 6 독립 프로젝트(Antura 안 씀). 빌드 방법은 README.

## 배경 (이전 프로젝트와의 관계)

- 전작: `jamaica8612/yeona-math-adventure-source` (수학 학습 게임, Antura 오버레이).
  그쪽 PR #1에 만 4세 트랙 + TTS + 폰트 수정이 들어 있음. 이 게임은 거기서 검증된
  패턴(코드 조립 UI, 정적 폰트 굽기, 클립 음성)을 가져와 새로 시작한 독립 앱.
- 사용자 결정 사항: **기기 TTS 사용 금지**(음성은 AI 생성 클립만), 폰트는 아이 취향
  (주아체 채택), 완전히 새 앱(새 레포).

## 로컬 검증 체크리스트

1. README대로 Unity 프로젝트 구성 → 컴파일 에러 0 확인
2. Test Runner EditMode 전부 통과
3. `Yeona Pet > Build > Android Debug APK` → 폰 설치
4. 확인: 한글이 주아체로 나오는지 / 당근이 입으로 날아가는지 / 문지르면 거품+깨끗해지는지 /
   재우기·깨우기 / 쓰다듬으면 하트 / 앱 재실행 시에도 텍스트 정상(3회 반복)
5. 음성 클립을 넣었다면 각 상호작용에서 재생 확인
