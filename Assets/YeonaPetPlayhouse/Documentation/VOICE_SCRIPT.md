# 음성 대본 (AI 음성 생성용)

기기 TTS를 쓰지 않는다. 아래 대사를 AI 음성(예: ElevenLabs, 수퍼톤, CLOVA Voice 등)으로
생성해 **파일명 = 키 이름**으로 저장하면 코드 수정 없이 게임에서 재생된다.

## 파일 규격

- 저장 경로: `Assets/YeonaPetPlayhouse/Resources/YeonaPetPlayhouse/Voice/`
- 파일명: 아래 표의 키 + 확장자 (예: `greeting.wav`)
- 형식: WAV 또는 OGG, 44.1kHz, 모노 권장. MP3도 동작.
- 목소리 톤: 4세 아이에게 말하는 밝고 다정한 목소리. 별냥이(아기 고양이) "나비"의 목소리는
  약간 높은 톤(아이 친구 느낌), 문장 끝을 올려서. 속도는 보통보다 10% 느리게.
- 클립이 없으면 그 대사만 조용히 생략된다 (게임 진행에는 지장 없음).

## 생성 팁

- 13개를 같은 목소리·같은 세션으로 한 번에 생성해서 톤을 통일할 것.
- 효과음(뿅, 반짝, 물소리)은 별도 폴더 `Resources/YeonaPetPlayhouse/Sfx/` 예정 —
  2단계에서 코드 훅 추가 후 안내.
- 새 대사를 추가하려면: 코드에서 `PetVoice.Play("키")` 호출 추가 + 이 표에 행 추가 +
  파일 생성. 끝.
