# 펫 기능 로드맵 — 상용 앱 벤치마크 기반

토킹톰/안젤라, Bubbu, Pou, 토카 펫츠, 사고미니, 다마고치류의 기능을 조사해
**만 4세 · 무실패 · 무과금 · 오프라인 · 글자 최소** 필터로 걸러 채택한 목록.
구현 순서는 아래 단계(P1→P3)를 따른다. 새 기능 아이디어는 이 문서에 먼저 추가할 것.

## 벤치마크 요약 — 상용 앱에서 배울 것 / 버릴 것

| 상용 앱 | 배울 것 (채택) | 버릴 것 (이유) |
|---|---|---|
| 토킹톰 | **부위별 터치 리액션**(머리/배/발이 다르게 반응), 리액션의 다양성 | 마이크 따라하기(권한·프라이버시), 코인·광고(가족정책/무과금), 때리기 리액션(정서) |
| Bubbu | **먹이 다양화**, **방 확장**(욕실 분리), 목욕 연출(샤워기+거품), 감정 표현 밀도 | 과금 상점, 복잡한 요리 시스템(4세에겐 단계 과다) |
| Pou | **욕구 4종의 단순함**(배고픔/청결/에너지/재미), 방 전환 UX | 포션·레벨 숫자(글자/숫자 의존) |
| 토카 펫츠·사고미니 | **무실패 철학**, 같은 행동에도 매번 조금 다른 반응, 숨은 이스터에그 | (거의 없음 — 철학 기준점) |
| 다마고치류 | **성장 단계**(아기→어린이)의 애착 형성 | 죽음/가출 페널티(절대 금지), 시간 압박 |

## 핵심 원칙 (변경 금지)

1. **무실패**: 어떤 방치·행동도 벌하지 않는다. 나비는 슬퍼하지 않고 "원하는 것"을 알려줄 뿐.
2. **한 번에 한 가지**: 욕구 표현은 항상 가장 강한 것 하나만.
3. **글자 없이 플레이 가능**: 모든 정보는 그림+음성. 텍스트는 장식.
4. **반응 다양성**: 같은 상호작용에 음성/애니 2~3종 랜덤 — 상용 감각의 핵심.
5. 무과금·무광고·오프라인·권한 없음 (구글 가족정책 대비).

## P1 — 재미 밀도 (v0.2, 첫 빌드 검증 직후)

1. **욕구 4종으로 확장**: 배고픔/청결/졸림 + **심심함(놀이)**. PetCore에 `Boredom` 추가,
   공놀이로 해소. (Pou의 4욕구 구조)
2. **공놀이**: 바닥에 공이 항상 있음. 드래그해서 던지면 나비가 통통 쫓아가 물고 온다
   → 하트+웃음. (토카 펫츠식 오브젝트 상호작용)
3. **먹이 트레이**: 당근 버튼 → 먹이 3종 트레이(당근/우유/생선과자)가 펼쳐지고
   골라서 준다. 좋아하는 것(생선과자)이면 리액션 강화, 어떤 것도 거부하지 않음.
4. **부위별 터치**: 머리(눈 감고 갸르릉) / 배(까르르 웃음) / 꼬리(살랑살랑) 각각
   다른 애니메이션+음성. (토킹톰의 핵심 재미)
5. **살아있는 대기 모션**: 3~7초마다 눈 깜빡임, 가끔 귀 씰룩, 꼬리 흔들기,
   하품(졸릴 때). 코드 애니메이션으로 구현 — 상용 체감의 8할.
6. **목욕 연출 강화**: 문지를 때 거품이 나비 몸에 쌓였다가 반짝하며 터지고,
   물방울 튀는 효과. 완료 시 몸이 반짝반짝. (Bubbu 목욕신 참고)

## P2 — 애착·수집 (v0.3)

7. **성장 단계**: 누적 돌봄 횟수로 아기 나비 → 어린이 나비 (외형 조금 커지고 리본).
   되돌아가지 않음, 숫자 안 보여줌. (다마고치의 애착 요소만 채택)
8. **꾸미기 해금**: 리본/모자/목도리 3종 — 돌봄 누적으로 자동 해금되어 선물 상자로
   등장(코인·상점 없음). 착용은 옷장 버튼에서 드래그.
9. **욕실 방 분리**: 화살표로 거실↔욕실 이동. 목욕은 욕실에서(욕조+샤워기).
   방마다 배경·소품 다름. (Bubbu 방 구조의 최소 버전)
10. **사진 버튼**: 지금 화면을 로컬 갤러리에 저장(부모가 아이 작품 보관용).
    권한 없는 앱 내 갤러리로.

## P3 — 확장 (v0.4+)

11. 미니 놀이 2종: 까꿍(나비가 숨고 찾기), 비눗방울 터뜨리기
12. 실제 시간 연동 낮/밤 배경 + 밤에는 자장가 BGM
13. 이스터에그: 창문 두드리면 새가 날아옴, 러그 들추면 나비가 놀람 등 3~5개
14. (검토) 3D 나비 전환 — Quaternius/에셋스토어 리깅 모델, 2.5D RenderTexture 방식

- 음성 대본은 기능 추가 시 VOICE_SCRIPT.md에 행 추가 (P1 예상 추가분:
  공놀이 3종, 먹이별 리액션 3종, 부위별 3종, 하품 1종 ≈ 10개).
- 아트 추가분은 ART_REQUEST.md에 발주 행 추가 (공, 먹이 2종, 리본/모자 등).
