# Source publication manifest

## Included

- Complete `Assets/YeonaMathAdventure` tree, including Unity `.meta` files
- Required package-specific Antura analytics privacy patch
- Android/player/build-scene project settings
- Unity version and exact upstream Antura commit
- Tests, documentation, licenses, font, generated project art and provenance

## Deliberately excluded

- Unmodified Antura files already available from the upstream repository
- Unity and Gradle caches
- Locally installed Android build tools
- APKs and other compiled outputs
- Device/user save data
- Credentials and signing keys

This layout keeps the publication small while retaining every Yeona-specific source file and the information required to reconstruct the Unity project.
